# ulju-news-scrap

울주군 실·국·보건소·의회사무국·읍면 키워드를 실행할 때마다 구글 뉴스 RSS로 실시간 검색해 보여주는 기사 스크랩 앱.
([saeul-newsscrape](https://github.com/syhanet-creator/saeul-newsscrape)와 같은 구조·기능)

## 실행
```
python news_scrap.py
```
또는 `실행.bat` 더블클릭. 브라우저가 자동으로 열립니다 (http://127.0.0.1:8766/).

- Python 3 표준 라이브러리만 사용 (설치 불필요)
- 탭·키워드는 `newscore.py`의 `TABS_CFG`에서 수정 (서버와 화면이 `/api/tabs`로 같은 설정을 씁니다)

- **관련성 규칙**: 과·국·읍면 이름은 다른 지자체에도 있어 구글 검색식에 `"울주군"`을 함께 넣고, 결과도 **제목에 '울주' 또는 그 키워드 이름이 있어야** 인정합니다(`newscore.py`의 `title_relevant`). 울주신문 기사는 울주군 소식이라 제목 검사를 하지 않습니다.
- 지역 신문은 탭마다 읽는 곳이 다릅니다(`TABS_CFG`의 `local`: `True`=8곳 전부, 목록=그 신문만, 없음=구글 뉴스만).
- 탭 바와 칩 바는 마우스는 손 모양으로 끌어서, 모바일은 밀어서 이동합니다.
- 요청 기간(`days`)은 1·3·7·14·30일 중 하나로 맞춰집니다.

## 기능
- 출처: 구글 뉴스 RSS + 울산 지역 신문 8곳(울산뉴스넷·울주신문·울산시민신문·울산신문·경상일보·울산제일일보·울산종합일보·울산매일)
- 유사 기사 묶기: 제목 유사도로 같은 사안의 기사를 네모 상자로 묶어 표시
- 스팸·광고(도박·게임 사이트 등)는 서버가 항상 제외 (`newscore.py`의 `BLOCKED_SOURCES`, `SPAM_RE`)
- 기자 이름: 지역 신문은 목록·본문에서, 구글 뉴스 기사는 같은 신문사 기사를 빙에서 찾아 읽습니다. 못 얻으면 '기자 미확인'
- 울산뉴스넷·울주신문: 서버가 사이트에 못 닿는 날엔 이 브라우저에 기억해 둔 기사를 채우고 뒤에서 다시 요청합니다.
- 스크랩: ☆ 클릭으로 저장(브라우저 저장), CSV 내보내기·목록 복사
- 주간 AI 요약: 탭마다 최근 7일 기사를 AI로 요약(1시간 공유). 메인 탭은 매주 처음 열 때 자동 생성
  - 환경변수 `GEMINI_API_KEY`(Google AI Studio 무료 키) 또는 `ANTHROPIC_API_KEY` 중 하나 필요. 둘 다 있으면 Gemini 우선
  - 로컬: `$env:GEMINI_API_KEY="..."` 후 실행 / Vercel: Project Settings -> Environment Variables 추가 후 Redeploy
  - 모델 변경: `GEMINI_MODEL`, `SUMMARY_MODEL`(Claude)
- 모바일 최적화·PWA(홈 화면 설치, 오프라인에서 마지막 목록)

## 배포 (Vercel)
